# DocumentSearch

Утилита для полнотекстового поиска по документам на сетевом диске. Аналог DataSearch для SberOS. Работает без установки сторонних библиотек, только стандартный Python 3, который уже есть в операционной системе.

## Что умеет

- Индексирует PDF, DOCX, XLSX, TXT, CSV с SMB-шары
- Полнотекстовый поиск с поддержкой AND / OR / точных фраз и скобок
- Поиск регистронезависимый: `Иванов`, `иванов`, `ИВАНОВ` дадут одинаковый результат
- Поиск по подстроке: `заключен` найдет "заключение", "заключения", "заключен"
- Показывает фрагмент текста рядом с найденным словом
- Открывает найденный файл прямо из терминала
- При повторном запуске переиндексирует только изменившиеся файлы
- Хранит индекс локально в SQLite, повторный поиск не требует подключения к серверу
- Ctrl+C не ломает индекс, все сохраненные данные остаются целыми

## Требования

- SberOS / Linux
- Python 3.6+ (уже в системе)
- `smbclient` для подключения к шаре

Формат `config.ini`:

```ini
[connection]
login      = ivanov_ii
password   = ВашПароль
server     = //адрес_сервера/шара
share_path = ПАПКА_НА_ШАРЕ
```

## Запуск

```bash
python3 search.py
```

При первом запуске выбрать пункт "Создать индекс". Утилита пройдет по шаре, скачает и проиндексирует все документы. Время зависит от объема, 157к документов занимает около 10 часов.

При следующих запусках обновляются только новые и измененные файлы, это занимает секунды или минуты.

## Синтаксис поиска

| Запрос | Что ищет |
|--------|----------|
| `компания заключение` | оба слова в документе |
| `компания1 AND компания2` | то же самое, явно |
| `Петров OR Иванов` | любое из слов |
| `"Заключение ИНН"` | точная фраза |
| `(Иванов Иван Иванович OR Иванов И.И.) AND Заключение` | комбинации со скобками |

Поиск по подстроке работает автоматически: запрос `заключен` найдет все формы слова.
Регистр не важен: `ДОГОВОР` и `договор` дадут одинаковый результат.
